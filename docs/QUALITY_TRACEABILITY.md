| Quality attribute | Scenario | Tactic | Actual code paths | How to demonstrate it | Status |
|---|---|---|---|---|---|
| Availability | A branch network or device becomes unavailable and later recovers. | Device-fault isolation; adapters; simulator recovery scenario. | `/server/src/simulator/index.ts`; `/server/src/domain/circulationService.ts`; `/server/src/integration/adapters.ts`; `/server/src/events/bus.ts`; `/server/src/persistence/repositories.ts` | Call `POST /api/simulator/scenario` with `device_offline`, `network_outage`, and `recover`; observe device status events. | implemented |
| Security | Unauthenticated or incorrectly privileged users attempt protected realtime or simulator operations. | Auth/RBAC middleware; server-side authorization; audit log. | `/server/src/api/auth.ts`; `/server/src/api/server.ts`; `/server/src/api/library.ts`; `/server/src/persistence/repositories.ts` | Verify reader sessions cannot access `/api/stream` or simulator controls; verify librarian/admin sessions can. | implemented |
| Performance | Concurrent telemetry bursts and circulation events must not be lost while wallboard clients receive updates. | In-process Pub-Sub; 500 ms telemetry batching; SQLite rollups; SSE replay IDs. | `/server/src/events/bus.ts`; `/server/src/integration/telemetryPipeline.ts`; `/server/src/api/stream.ts`; `/server/src/domain/circulationService.ts`; `/server/src/persistence/repositories.ts` | `server/src/integration/telemetryPipeline.test.ts` verifies 500/500 persistence; `server/src/events/bus.test.ts` verifies handler isolation and duration logging; `/api/stream` replays after `Last-Event-ID`. | implemented |
| Modifiability | A new device protocol or vendor is introduced without changing domain contracts. | Adapter + Factory; normalized payloads; legacy polling adapter. | `/server/src/integration/types.ts`; `/server/src/integration/adapters.ts`; `/server/src/integration/factory.ts`; `/server/src/domain/loanPolicy.ts`; `/server/src/persistence/repositories.ts` | `server/src/integration/adapters.test.ts` exercises TCP RFID, HTTP camera/sensor, gate, mock, and legacy adapters behind one contract. | implemented |
| Usability | A reader uses the kiosk circulation workflow. | Task-focused kiosk flow; bilingual UI; explicit state transitions. | `/web/src/kiosk`; `/web/src/shared`; `/server/src/domain/circulationService.ts` | Walk through login, scan, borrow/return, and completion in both supported languages. | planned |
| Testability | A developer injects deterministic telemetry, faults, circulation, and network scenarios without hardware. | Deterministic simulator; scenario controls; repository boundaries; Vitest. | `/server/src/simulator/index.ts`; `/server/src/domain/alertRules.ts`; `/server/src/events/bus.ts`; `/server/src/persistence/repositories.ts`; `/server/src/integration/telemetryPipeline.ts`; `/server/src/**/*.test.ts` | `npm test -w server` passes 9 tests covering bus isolation, adapter contracts, threshold de-duplication, overload no-loss, and dirty data. | implemented |
